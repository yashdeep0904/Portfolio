# Yashdeep - Personal Portfolio 🚀

A clean, responsive, and modern personal portfolio website built with pure HTML, CSS, and JavaScript. This project showcases a modern glassmorphism design, smooth CSS animations, and dynamic content rendering without the need for heavy frameworks or build tools.

## ✨ Features

* **Zero Dependencies:** Built entirely with vanilla HTML5, CSS3, and JavaScript (ES6+).
* **Modern UI/UX:** Features a gradient background, glassmorphism card effects, and floating blur blobs.
* **Fully Responsive:** Fluid layouts using CSS Flexbox and Grid that adapt perfectly to mobile, tablet, and desktop screens.
* **Dynamic Rendering:** Project cards and skill tags are injected dynamically via JavaScript, making it easy to update content without touching the HTML.
* **Smooth Animations:** Hover states, scaling effects, and background pulsing animations handled purely via CSS.
* **Vector Icons:** Integrates [Lucide Icons](https://lucide.dev/) and [FontAwesome](https://fontawesome.com/) via CDN for crisp, scalable graphics.
